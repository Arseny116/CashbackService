**Бэкенд-сервис на C#  для динамического начисления кэшбэка и персонализированных кредитных предложений.**

Проект построен по принципам **Domain-Driven Design (DDD)**, **CQRS** и **Event-Driven Architecture** с разделением на два микросервиса, взаимодействующих через **gRPC**.

## 📋 Бизнес-контекст

Сервис управляет персонализацией банковских продуктов в реальном времени:

- **Динамический кэшбэк** — ставка зависит от категории трат клиента, партнеров и статуса
- **Персональные кредитные предложения** — индивидуальная сумма и ставка на основе spending-аналитики
- **Защита от дублей** — одна транзакция не может быть обработана дважды
- **Аудит и прозрачность** — полная история изменений через Event Sourcing

## 🏗️ Архитектура

### Микросервисы

| Сервис | Назначение | API |
|--------|-----------|-----|
| **TransactionService** | Прием транзакций, расчет кэшбэка, аналитика трат | REST (внешний) + gRPC Server (внутренний) |
| **CreditOfferService** | Генерация и управление кредитными предложениями | REST (внешний) + gRPC Client (внутренний) |

### Коммуникация

Клиенты → REST (JSON) → Сервисы
Сервис ↔ Сервис → gRPC (Protobuf)

### Стек

| Технология | Назначение |
|------------|-----------|
| **.NET 8** | Платформа |
| **ASP.NET Core** | REST API |
| **gRPC** | Межсервисное взаимодействие |
| **MediatR** | CQRS + Event Handling |
| **PostgreSQL** | Основное хранилище + Event Store |
| **Redis** | Кэширование Read Model |
| **Kafka** | Асинхронные события (опционально) |
| **Docker** | Контейнеризация |


### Поднять всё одной командой
docker-compose up -d


API:
POST /api/v1/transactions — Создать транзакцию  
GET /api/v1/clients/{clientId}/cashback — Баланс бонусов  
GET /api/v1/clients/{clientId}/transactions — История транзакций  
GET /api/v1/clients/{clientId}/categories — Категории трат клиента  
GET /api/v1/clients/{clientId}/profile — Профиль клиента  
POST /api/v1/clients — Зарегистрировать клиента  
GET /api/v1/offers/active/{clientId} — Активное предложение  
POST /api/v1/offers/{offerId}/accept — Принять предложение  
POST /api/v1/offers/{offerId}/decline — Отклонить предложение
